# table_a5000_guidance_absolute

Reference table: absolute `dense_mean` / `arm_mean` per guidance setting and metric from the unified table.

- Source CSV: `outputs/a5000_guidance_sweep_v1/analysis/delta_table_unified.csv` (CFG rows computed by `experiments/analyze_a5000_guidance_v1.py` from `outputs/a5000_guidance_sweep_v1/{clap_scores.csv, aqascore/sample_scores.csv, audiobox/sample_scores.csv}`; the No CFG row copied from `outputs/no_cfg_v1/analysis/delta_table.csv`, same protocol, not recomputed).
- Statistical protocol: prompt = unit of analysis (3 seeds averaged); Δ = condition − Dense at the same guidance setting and prompt; 95 % CI from 10,000 prompt-level bootstrap resamples, rng seed 20261024; 24 prompts (experiments/prompts/cast_diagnostic_v1.json), seeds 42/123/2026, 100-step PNDM, 256×1024 mel, fp16, α=1.5, deterministic self-attention, 16 attn2 modules only.
- Hardware: NVIDIA RTX A5000 for all four settings (`outputs/*/experiment_manifest.json` → `versions.gpu`).
- Generated by `experiments/make_final_paper_assets.py` (reads tables only; no audio, no inference).
