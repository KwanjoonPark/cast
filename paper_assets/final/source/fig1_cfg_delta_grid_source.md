# fig1_cfg_delta_grid

- Source CSV (CFG sweep): `outputs/cfg_sweep_v1/analysis/delta_table.csv` — columns `metric, cfg, arm, dense_mean, arm_mean, delta, ci_lo, ci_hi`; generated on NVIDIA GeForce RTX 2080.
- Source CSV (no-CFG): `outputs/no_cfg_v1/analysis/delta_table.csv` — same columns (`condition` = no_cfg, guidance_scale = 1.0); generated on NVIDIA RTX A5000.
- Hardware names: `outputs/*/experiment_manifest.json` → `versions.gpu`.
- Statistical protocol (unchanged, from the analysis scripts): prompt = unit of analysis (3 seeds averaged); Δ = condition − Dense at the same guidance setting and prompt; 95 % CI from 10,000 prompt-level bootstrap resamples, rng seed 20261024; 24 prompts (experiments/prompts/cast_diagnostic_v1.json), seeds 42/123/2026, 100-step PNDM, 256×1024 mel, fp16, α=1.5, deterministic self-attention, 16 attn2 modules only.
- Generated by `experiments/make_final_paper_assets.py` (reads tables only; no audio, no inference).
